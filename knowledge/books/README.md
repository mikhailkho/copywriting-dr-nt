# books/ — your own notes (not published)

This folder is empty on purpose. The skill works without it: the framework notes carry the attributions and the method.

If you own the books and want the skill to draw on your reading, add your own notes here, one file per book. Everything in this folder except this README is git-ignored, so it stays on your machine.

## Rules for your notes
- Write in your own words. Do not paste passages from the book.
- Keep quotes to a few words, for attribution only.
- Record what you actually read in depth and what you only skimmed.
- Mark dated material separately from durable principles.

## Template (`books/<slug>.md`)
```
# <Title> — <Author> (<year>, <edition>)
Role in my library:
Core thesis (my words):
Frameworks, with chapter pointers:
Durable principles:
Dated or risky material:
How I would use this with AI:
Read in depth / skimmed:
```

After adding a note, tell Claude it exists (for example in your request: "also use my notes in knowledge/books/"). Mode H (library Q&A) will read it.
