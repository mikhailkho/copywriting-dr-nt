# copywriting-dr-nt — Knowledge Library

A distilled, cross-referenced library of classic direct-response copywriting and marketing wisdom, organised to be loaded **progressively** by the skill (read only what the job needs).

**Important:** the library contains *our own summaries, frameworks and paraphrases* of the source works. It does **not** include the books or their text. Short phrases are used only as attributions or labels. Source PDFs live outside the repo, and the per-book notes behind this library are not published (see `books/README.md`).

## How to use
1. Start with `00-neo-traditionalist-canon.md` (principles + conflict resolutions).
2. Load the framework files relevant to the job (see decision guide below).
3. Load the channel adapter for the deliverable.
4. Use the checklists before delivery.
5. For depth on one author, use the attributions in the framework notes, or add your own private notes in `books/` (see `books/README.md`).

## Contents

### Sources (influences)
The frameworks draw on the work of Claude Hopkins, Gary Halbert, Eugene Schwartz, John Caples, Drew Eric Whitman, Michael Masterson and John Forde, Dan Kennedy, Robert Bly, Todd Brown and Russell Brunson. They are named as influences and for attribution only. None of them has reviewed or endorsed this project. The per-book notes are not published. You can keep your own in `books/` (git-ignored); see `books/README.md`.

## Provenance & coverage notes
- Numerical claims (response rates, revenue) are the authors' own and unverified. They illustrate mechanisms, not benchmarks.
- Old examples are dated; the notes separate **Durable** from **Dated** material for each source.
- If a topic is not covered here, the skill should say so rather than infer.

## Maintenance
- Add new learnings to a project-level results log (`templates/results-log.csv`), not to this library, unless they generalise.
- When adding a book to your private `books/` folder, create `books/<slug>.md` with: role in library, thesis, frameworks (with chapter pointers), dated vs durable, AI-era use. Then update the framework files it affects and this README.
